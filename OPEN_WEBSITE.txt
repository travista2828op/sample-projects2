🎯 QUICK CUSTOMIZATION
═══════════════════════════════════════════════════════════════════════════════

Change Content:
└─ Edit app/components/*.tsx files

Change Colors:
└─ Edit app/globals.css (line 3-6)

Change Fonts:
└─ Edit app/layout.tsx

Add Animations:
└─ Modify Framer Motion props in components

Change 3D Effects:
└─ Edit app/components/Hero3D.tsx parameters
